# Smith & Found

**Andy Smith — Finder of Interesting Things**

A road-trip treasure-hunting brand built for GitHub + Netlify.

## Upload these files to the root of your GitHub repo

- `index.html`
- `styles.css`
- `script.js`
- `thank-you.html`
- `netlify.toml`
- `.pages.yml`
- `admin/index.html`
- `data/finds.json`
- `data/status.json`
- `media/` folder

## Netlify

Connect the repo to Netlify and publish from the repository root. No build command is required.

### Forms

The site contains two Netlify Forms:

- `find-it`
- `show-andy`

In Netlify, enable form detection and add an email notification to:

`minerinoregon@gmail.com`

### Phone updates

The site is configured for Pages CMS:

https://app.pagescms.org/

Authorize the Smith & Found repo. Andy can then update:

- Road Finds
- Where's Andy?

The `/admin/` page links directly to the editor.
